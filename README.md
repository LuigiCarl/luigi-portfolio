# Luigi Carl Brezuela — Portfolio

A personal developer portfolio featuring my projects, technical skills, experience, and downloadable resume.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Check

```bash
npm run lint
npm run build
```
